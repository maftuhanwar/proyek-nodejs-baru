# Proyek Node.js Baru

## Deskripsi
Proyek ini merupakan latihan dasar menggunakan Node.js. Program akan menampilkan tulisan "hello world" pada console ketika dijalankan.

## Teknologi
- Node.js
- JavaScript
- Git
- GitHub

## Struktur Folder

```text
proyek-nodejs-baru/
├── README.md
├── package.json
├── index.js
└── src/
    └── index.js
```

## Cara Menjalankan Program

**Cara 1: Menggunakan Node.js**

```bash
node src/index.js
```

**Cara 2: Menggunakan NPM**

```bash
npm start
```

## Output

```text
hello world
```

## Tujuan
Mempelajari dasar penggunaan Node.js, pengelolaan package.json, serta integrasi proyek dengan Git dan GitHub.
